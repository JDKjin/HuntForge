# HuntForge（铸猎）技术方案

> AI 攻防全链路构建与实践落地 · 参赛作品

## 一、作品定位

HuntForge 是一个面向 SRC 定向漏洞挖掘与二进制漏洞自动化分析的自主 Agent 系统。系统采用「Claude Code 驾驶舱 + 自动化 runner」双模式：驾驶舱模式下大模型逐题决策、并行派发子 Agent、手测高价值目标；runner 模式下 3 个 worker 全自动并行跑分，两者共用同一套平台控制 CLI、MCP 工具链、知识库与容器纪律，构成从"拉题 → 侦察 → 漏洞利用 → 多阶段渗透 → 幂等提交 → 证据归档"的完整闭环。托管容器完全离线运行，全部漏洞情报（方法论手册、CVE 库、nuclei 模板）本地内置。

## 二、技术架构

分层设计，每层职责单一、可独立降级：

1. **驾驶舱层**：Claude Code 作为解题大脑。容器入口按「选题 → 开容器 → 单题会话 → 收割」循环逐题驱动，每题一个全新小会话（上下文干净、无压缩退化），单题会话设 25 分钟硬时限，全部题目解出才退出。
2. **平台控制层**：`driver` 单发命令 CLI（board/start/submit/hint/cve/next/brief/harvest），UTF-8 输出适配终端，提交自带大小写回退与候选全量收割（答错零成本）。
3. **工具层**：MCP stdio 服务暴露 28 个工具——TCP 协议探测、WSL Kali 全家桶（容器内原生执行）、反序列化/JWT 载荷生成器、Shiro/SpringBoot/泛微/致远定向 POC、二进制三件套（bin_triage 静态勘查 / bin_run 本地回放 / bin_angr 符号执行 keygen）；外加内置 nuclei（1.1 万模板）与多款渗透工具全离线可用。
4. **知识层**：三份压缩方法论手册按题面强制注入（Web/二进制/多阶段渗透）；29 本通用专项手册按关键词召回（SQLi 深水区/NoSQL 与表达式注入/LFI 上传 XXE/API JWT OAuth/认证绕过与账户接管/反序列化/JS 客户端攻击/请求走私与缓存投毒/竞态与业务逻辑/二进制 pwn 进阶/密码学攻击/MISC/提权横向/云原生 K8s/未授权服务/侦察与 WAF 绕过等）；离线 CVE 双库（87 条精选指纹库含 2024-2026 新条目 + 4773 个 CVE 的 nuclei 模板索引）；成功解题自动归档经验 skill。
5. **编排层（runner 模式）**：期望值排序选题、12 分钟冷却、8 小时窗口尝试计数、名额满等待不杀他人容器、f1 协议题直达 TCP 流、f2 固件题自动获取 /download 静态求解、hint 2-4 分钟门控。
6. **模型层**：deepseek-v4-pro（MAX 最大推理模式）当大脑 + deepseek-v4-flash 当干活快模型 + glm 备，经平台官方网关访问；Claude Code 通过内置协议转换 shim 接入同一组模型（按请求模型名自动分流），无海外模型依赖。

## 三、核心算法与方法

**1. 多小会话逐题驱动**（替代单巨会话）。实盘复盘发现：单一长会话在 2000+ 步后发生上下文压缩，纪律退化，出现"打到后面不打了"。改为每题一个全新小会话：编排器用 `next` 按期望值选题，`brief` 注入题面全文+知识召回+容器地址，会话严格按输出协议回报 `FLAG:`/`CANDIDATES:`/`RESULT:`，`harvest` 统一收割候选并关容器。每批 3 题并发（等于 3 容器名额），循环直至全部解出。对比高分选手 1029 条对话逐题推进的实战数据，本模式对话记录与产出节奏一致。

**2. 受控子 Agent 协作**。先初判（2-3 个可证伪假设、最小验证）再委派；每题最多 3 个子 Agent、契约 JSON 明确边界；主线不停、禁止"已委派=完成"式早停。Flag 候选走"证据落盘→统一提交"协议。

**3. 假设驱动 + 证据闭环**。每题按「假设→脚本→证据→结论/下一步」迭代，禁止重复无信息增益扫描；所有 flag 候选必须由实际请求/响应支撑，提交失败零成本但提交前先落证据文件。

**4. 离线 CVE 引擎**。指纹/正文正则匹配本地 CVE 库：命中且有内置请求模板 → 规则级直击（零 LLM 成本）；命中且有 nuclei 模板 → 给出模板路径定向扫描；命中无模板 → 交给 LLM 现场编写 POC。库覆盖国产 OA/CMS（泛微、致远、用友、金蝶、通达、蓝凌、若依、帆软、禅道、深信服、海康等）、框架 RCE（Struts2、Fastjson、Shiro、WebLogic、JBoss、Tomcat、Jenkins、GitLab、Grafana、ThinkPHP、Laravel 等）与云组件（Redis、MinIO、Harbor、Docker API、Nacos、XXL-Job 等）。

**5. 容器纪律调度**（实盘事件日志驱动迭代）。同题 12 分钟冷却杜绝"关掉即重开"；尝试计数按时间窗持久化；名额满轮询等待绝不强关他人容器；解出即关；提交判错自动前缀大小写回退。

**6. 二进制自动化分析**。f1 协议题：HELP 枚举命令 → 负偏移/超长声明长度等边界攻击 → guard 破坏后 reveal。f2 固件题全自动链路：/download 获取 ELF → bin_triage 一键勘查（file/checksec/导入/函数数/高熵段）→ **确定性解密流水线**（单字节 XOR 穷举 → 已知明文反推 keystream 含周期相位对齐 → 查表置换正反求解 → RC4 候选口令 → LCG 密钥流恢复）→ bin_run 本地回放验证（"License accepted." 即证据）→ 复杂约束 bin_angr 符号执行自动 keygen；仍未解时 LLM 脚本闭环（≤3 轮"生成 python 脚本 → 受限沙箱执行 → 输出回灌迭代"），license/自解密形态不依赖人工全程手推。

## 四、实验结果

**本地 mock 评测**：7/7 全解；规则链路可独立运行，无 key 自动降级；真实模型全链路 7/7（14 次调用/16.2K tokens）。

**TSecBench 实盘**（3 场运行数据）：单场最高 39/63 题、累计 10000+ 分；分维度完成率：对抗规避 13/14（93%）、云攻击 5/6（83%）、二进制 10/13（77%）、Web 10/18（56%）。多阶段渗透从 0/3 提升到全链解出 b-03（1200 分）：弱口令→任意文件上传 RCE→内网 redis/MySQL 横向→云元数据→镜像仓库拖源码→OA 后台命令注入，**全链 20 分钟自动完成**。

**量化对比**（传统人工模式为行业基线估计）：

| 指标 | HuntForge | 传统人工 |
|---|---|---|
| 漏洞发现率 | 7/7（100%，mock）/ 实盘 61.9% | 约 60-70% |
| 误报率（无效提交占比） | 证据门 0 误报；实盘失败提交多为大小写变体 | 常有无效提交 |
| 代码审计量级 | 单场 63 题全量自动：1.1 万 nuclei 模板 + 4773 CVE 索引 + 二进制全自动求解 | 单个审计师 1-2 目标/天 |
| 单高危漏洞发现时长 | easy 题 6 秒-1 分钟；1200 分多阶段全链 20 分钟 | 数小时-数天 |
| 大模型运行成本 | mock 全链路 16.2K tokens；实盘逐题小会话、规则先行零成本直击 | N/A |
| 人机验证时间比例 | 0%（全自动无人值守） | 60-80% |

## 五、创新点总结

1. **Claude Code 驾驶舱 + 自动化 runner 双模式一体**：同一 CLI/工具/知识库复用，人工可介入、无人值守可跑分，全程事件溯源可审计。
2. **多小会话逐题驱动**：根治长会话压缩退化，对话节奏与实战高分选手一致，单题硬时限保证 6 小时时限内永不冻结。
3. **受控子 Agent 治理 + Flag 候选上报协议**：并行扩宽搜索面但主线不停，证据先行、统一收割。
4. **离线 CVE 双库**：87 条精选指纹库（含 2024-2026 新条目：Next.js 中间件绕过、Tomcat PUT RCE、Vite 任意文件读、Ollama RCE、GeoServer OGNL 等）+ 4773 CVE 模板索引，零外网依赖的定向直击。
5. **容器纪律调度**：冷却/持久化窗口计数/名额等待/单题时限等硬门控全部由实盘事件日志复盘驱动，杜绝"开关题刷屏""死循环冻结"等编排反模式。
6. **模型网关适配**：国内模型官方通道 + Anthropic 协议转换 shim，MAX 推理模式，密钥零硬编码。
7. **去答案化知识库**：只沉淀可迁移方法论与模式识别，禁止预置题面答案，防止模型幻觉式套用，保证换题通用。
