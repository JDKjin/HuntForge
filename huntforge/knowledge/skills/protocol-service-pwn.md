# TCP 行协议服务漏洞挖掘手册

适用题型（命中即召回本手册）：协议 TCP 行协议 缓冲 心跳 回显 偏移 服务
socket 端口 交互 写入 内存 守护。

f1 类远程协议服务的通用打法（script 写 socket 客户端，一次多轮交互）：

## 1. 握手与命令枚举
- 连上先收 banner（服务名/版本 = 大情报），依次发：空行、HELP、help、
  ?、VERSION、STATUS、LIST，看菜单与"未知命令"错误格式；
- 从菜单命令出发，每个命令试无参/单参/多参，记录成功与失败响应的差异。

## 2. 边界攻击（协议题核心）
- 偏移类写命令：试 0、最大偏移±1、**负偏移**（越界写 guard/相邻字段）、
  整数回绕（4294967295 类）；
- 长度类声明命令：声明长度远大于实际数据（心脏滴血式越界读回显内存）；
- 超长数据：把输入缓冲打满观察是否截断/溢出；
- 大小写/分隔符变体（\n \r\n 空格 tab）找解析差异。

## 3. 保护机制
- guard/canary 类字段：DUMP/STATUS 类命令常回显 guard 值，越界写坏它后
  REVEAL/show 类命令吐 flag——破坏 guard 是常见通关条件；
- 状态常只存活于单连接：完整攻击序列（写坏 guard → reveal）必须在同一
  连接内完成；每轮攻击前先确认状态是否被重置（DUMP 对比）。

## 4. 收尾
- 响应里直接找 flag 正则；溢出回显的数据按 flag{ 模式在整段内存里搜；
- 拿不到时逐字节扫描（heartbleed 场景把声明长度从小试到大，分段捞内存）。
