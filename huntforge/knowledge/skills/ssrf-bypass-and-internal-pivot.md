# SSRF 绕过与内网跳板手册

适用题型（命中即召回本手册）：SSRF 内网 探测 资产 网关 重定向 连通性 URL
代理 请求 转发 健康检查 导入 抓取 爬虫 订阅 回调。

SSRF 类题目的通用流程：确认注入点 → 判别过滤器类型 → 按类型绕过 →
内网侦察拿配置/凭据 → 打管理端点/内部服务。以下全部为通用方法。

## 1. 注入点与失败判别（先分清楚被什么拦了）
对每个 payload 观察错误信息区分三种情况：
- 返回"禁止/被阻止"类文案 → 命中字符串黑名单/关键字过滤 → 走编码绕过；
- 返回 DNS 解析失败 → 该名字不在内网名单（换名字/换解析方式）；
- 返回连接超时/拒绝 → 网络层拦截（IP 段封禁），换 IP 表示法。
判别准确才能选对绕过路径，不要盲目重试同一 payload。

## 2. 字符串黑名单绕过（按顺序试）
- %xx 编码主机名字符（字母/连字符/点都可以编码，服务端解析前会解码）；
- 大小写变体、主机名尾点（host.）、端口前尾点（host:port.）；
- IP 变体：整数十进制、八进制（0 前缀）、十六进制（0x）、省略段（127.1）；
- @ 用户信息段混淆（user@host）、反斜杠、URL 路径折叠（/a/../b/）；
- 重定向链：探测服务支持跟随重定向时，用允许的外部地址 30x 到内网地址
  （需要可控外部服务；无外网时跳过）；
- 协议走私：目标校验 http(s) 时试 gopher://、dict://、file://。

## 3. 内网侦察与配置获取
- 常见配置/健康端点：/debug/config /config /status /health /actuator/env
  /api/v1/all —— 返回的 JSON 里找 token/密钥/内网地址/数据库连接串；
- 拿到 token 后：管理端点常以 ?token= 或 ?admin_token= 收参，
  逐个组合路径（/admin/info、/admin/flag、/api/admin）与参数名枚举；
- 探测内网常见端口：80/443/5000/8000/8080/3306/6379，逐 IP 枚举。

## 4. 外带与利用
- 无回显时用 DNS/HTTP 外带（攻击机监听）；有回显直接读响应体。
- gopher:// 打 redis（写 crontab/webshell）、mysql（读文件）、fastcgi（RCE）
  按标准链走，注意 gopher payload 需要 URL 二次编码。
