# 导出/生成器类功能的命令注入手册

适用题型（命中即召回本手册）：导出 报表 生成 引擎 模板 预览 转换 打印 PDF
文件生成 报告 导入导出。

一类高频模式：应用把用户输入拼进 shell 命令生成文件（导出 TXT/PDF、转换、
渲染），响应里常回显完整命令模板或调试信息。通用利用流程：

## 1. 确认注入面
- 触发导出/生成并观察响应：若带 debug/command 字段（或报错回显命令），
  直接读出模板，逐字段判断哪个位置可控、哪个被转义。
- 无回显时按盲注思路：sleep/外带判定（`; sleep 5; #` 与基线耗时对比）。

## 2. 字段转义分析（关键）
- 单引号包裹 + 反斜杠/'' 转义（escapeshellarg 一类）→ 该字段不可直接注入；
- 双引号包裹且未转义 `$()` 反引号 → 用 $(cmd) 或 `cmd`；
- 直接拼进重定向路径/文件名的字段往往零过滤 → 优先打它：
  文件名 = `p; cmd > 可访问目录/win.txt; #`（# 注释掉尾部拼接的扩展名）；
- 数字字段（页码/尺寸）→ 试 $IFS 与 ; 组合。

## 3. 落地与取回
- 注入后把输出重定向到 Web 可达目录（如 uploads/），再 GET 取回；
- 或直接 curl 外带；flag 常规路径 /challenge/flag.txt（本平台）。
- 拿到执行能力后顺手 ls / 与 /challenge 确认目录布局，再精准读文件。

## 4. 黑名单对抗与邻机探测（实盘 bctf-14 模式）
- 黑名单逐项绕：`;`→换行 `#\n`（`#` 截断后续拼接）；空格→`$IFS`（`${IFS}`
  被禁时裸 `$IFS` 常合法）；关键词（flag）→通配 `/fla?`；`|`→`$()`。
- **无回显布尔 oracle**：每次执行 `cmd;echo $?` 或用 `true/false` 差分
  退出码，逐条件验证，不必逐字符盲注。
- **拷贝到 webroot 回读**：`cp$IFS/fla?$IFS/app/public/x.txt` 再 GET
  /static/x.txt——一分钟完成，比盲注快一个量级。
- **邻机探测**：题面只给附件站 IP，真实应用常在同 /24 邻机——按已知
  端口 80/8080/3000/4873/8443 扫 /24，按指纹（/login 302、响应头）定位
  真实目标再打。

## 5. 多目标
- brief 的【其他目标】列出的地址/端口都要扫一轮（npm 私服/次要服务
  常是另一段 flag 或入口）。
