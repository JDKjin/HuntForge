# 越权 / 批量赋值 / 任意文件读取手册

适用题型（命中即召回本手册）：越权 IDOR 批量赋值 更新 编辑 上传 凭证 附件
文件 下载 查看 系统字段 报销 审批 工单 订单。

## 1. 情报先行
- 前端 JS 注释与抓包响应里的隐藏字段名（路径字段、角色字段、价格字段）
  是最强线索——先扒全 JS 与每个 API 的完整响应体；
- API 返回里出现的系统字段（*_path、role、is_admin、price）都可作为
  覆写目标。

## 2. 批量赋值（mass assignment）
- 创建/更新接口常按"收到什么字段就写什么字段"处理：直接提交系统字段
  （如路径字段指向任意文件、role=admin、price=0）看是否生效；
- 更新接口多支持增量（部分字段）语义：只传一个字段即可，不必带全表单；
- 字段名黑名单不严时可大小写/加空格/数组形式（field[]=）绕过。

## 3. 任意文件读取落地
- 覆写文件路径字段后，配合下载/查看接口（download?id= / file?path= 类）读取；
- 或直接对下载接口本身做路径穿越（../、绝对路径、%2e%2e）；
- 目标：本平台 flag 常规路径 /challenge/flag.txt；也读 /etc/passwd、
  应用源码（找下一层漏洞）。

## 4. 通用越权
- 改 id/order_id/uuid 枚举相邻值（水平越权）；低权账号重放高权接口（垂直）；
- 改 X-Forwarded-For/X-Real-IP 伪装内网；换 HTTP 方法（GET→POST→PUT）重试。

## 5. 字段级鉴权差异（实盘 bctf-12 模式）
- 同一资源多个接口返回**不同字段集**：`resolve` 只返回脱敏 attrs（无
  bootstrap_credential），`lookup` 对同一引用**不做字段级鉴权**返回完整
  attrs → 内部下发凭据直接泄露。
- 打法：拿到一个节点/引用后，把同语义的兄弟接口全部打一遍
  （resolve/lookup/get/inspect/detail/describe），比字段集找差异；
- 引用链爬升：resolve 返回 parent_ref → 沿链爬到 root（staff→team→root），
  每层用"宽松接口"重读一次，逐层拿高权字段；
- 判据：两个接口返回同一 id 但字段数量不同 = 有字段级鉴权差异可挖。
